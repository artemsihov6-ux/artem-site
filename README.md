# artem-site

Личный сайт: услуги, лаборатория, отзывы, контакты. Чистый HTML/CSS/JS, без сборки.

## Как добавить отзыв на сайт

Форма на странице «Отзывы» присылает текст в Telegram. Чтобы опубликовать отзыв,
добавь его в `assets/reviews.json` и отправь изменения на GitHub:

```json
[
  {
    "name": "Имя клиента",
    "service": "Лендинг",
    "rating": 5,
    "text": "Текст отзыва.",
    "date": "ноябрь 2026"
  }
]
```

Несколько отзывов перечисляются через запятую. Поля `service` и `date` можно не указывать.
